prom-viewer

A read-only web UI and CLI for inspecting a running Prometheus instance.

It talks to Prometheus purely over its HTTP APIs. It never opens the TSDB directory, never writes to Prometheus, and needs no separate database, so pointing it at production is safe.

  • TSDB head — series, chunks, label pairs, time range and block counts.
  • WAL status — storage size and current segment, with replay progress while Prometheus is recovering.
  • Cardinality — top metric names, searchable, with per-label distinct-value counts for any one metric.
  • Recording rules — filterable rule groups with evaluation timing, health and source file.
  • Resource trends — one-hour CPU, memory and head-series graphs, queried from Prometheus itself.

Templates, CSS and a vendored copy of htmx are compiled into the binary with embed.FS, so deploying means copying one file. The PromQL expressions are fixed and read-only; there is no endpoint for entering arbitrary queries, which keeps the footgun surface small.
