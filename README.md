# portfolio

A portfolio website, written in Go and htmx.

`
ghcr.io/vishnukumarkvs/portfolio
`

---

### Run locally

```sh
go run .                        # http://localhost:8080
```

Or with Docker:

```sh
docker build -t portfolio .
docker run --rm -p 8080:8080 portfolio
```
